Sisäinen lähete – tulostussivu
Pieni GitHub Pages -sovellus, joka avaa alkuperäisen lähetepohjan PDF-tiedostona tulostamista varten.
Käyttöönotto GitHubissa
Luo GitHubiin uusi repository.
Pura tämän paketin sisältö repositoryn juureen.
Lisää ja commitoi tiedostot.
Avaa repositoryn Settings → Pages.
Valitse Deploy from a branch, branchiksi `main` ja kansioksi `/ (root)`.
Tallenna. GitHub Pages antaa sivun verkko-osoitteen.
Käyttö
Avaa julkaistu sivu ja paina Avaa lähete ja tulosta. PDF avautuu selaimen omaan PDF-näkymään, josta sen voi tulostaa.
Potilaan nimi ja henkilötunnus täydennetään paperille käsin. Sovellus ei pyydä eikä käsittele potilastietoja.
Huomio alkuperäisestä PDF:stä
`assets/lahete.pdf` on toimitettu skannattu lomake sellaisenaan. Tämä säilyttää logon, tekstit, ruudut ja asettelun mahdollisimman tarkasti. Koska lähde on skannaus, tulostusjäljen terävyys ei voi olla parempi kuin alkuperäisessä skannissa.
